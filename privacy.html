개인정보 처리 안내

겨울 간식 지도(snackmap.kr)는 회원가입이 없고, 필요한 정보만 다뤄요. 아래는 이 사이트가 실제로 저장하는 것들이에요.

1. 무엇을, 왜, 언제까지

언제저장하는 것쓰는 곳보관
사장님 신청연락처, 한마디(선택)가게 사장님이 맞는지 확인. 운영자만 볼 수 있어요승인하면 바로 자동 삭제. 승인하지 않은 신청은 운영자가 확인한 뒤 삭제
사장님 신청브라우저 키의 해시, 신청한 가게승인된 사장님을 알아보기신청을 지울 때까지
가게 등록가게 이름·위치·메뉴 등 입력한 내용지도에 공개가게를 지울 때까지
열림·닫힘 제보가게, 열림·닫힘, 시각, 사장님이 누른 것인지 여부 (손님이 누구인지는 저장하지 않아요)영업 상태 표시운영자가 지울 때까지
위치 수정 제안지도에서 고른 자리, 브라우저 키의 해시가게 위치 고치기, 중복 확인운영자가 지울 때까지
잘못된 정보 신고신고 이유, IP 해시같은 사람이 여러 번 신고하는 것 막기IP 해시는 30일이 지나면 다음 신고가 들어올 때 삭제
등록·제보·신고·신청·제안IP 해시, 브라우저 키의 해시, 시각너무 잦은 요청 막기2일이 지나면 다음 요청이 들어올 때 삭제

IP 원문은 우리 데이터베이스에 저장하지 않고, 이 사이트만 아는 값을 섞어 바꾼 해시만 저장해요.

2. 내 위치

위치는 폰에서 허용했을 때만 써요. 열림·닫힘 제보와 위치 수정 제안을 할 때 가게 근처인지 확인하려고 서버로 보내 거리만 계산하고, 우리 데이터베이스에 저장하지 않아요. "내 주변"은 브라우저 안에서만 계산해요. 허용하지 않아도 지도와 가게 정보는 볼 수 있어요.

3. 이 브라우저에 저장되는 것

사장님 확인과 중복 방지에 쓰는 무작위 키, 신고한 가게 번호가 브라우저(localStorage)에 저장돼요. 브라우저의 사이트 데이터를 지우면 없어져요. 광고나 방문자 추적 도구는 쓰지 않아요.

4. 함께 쓰는 서비스

  • Supabase: 위 정보를 저장하는 데이터베이스
  • GitHub Pages: 사이트 화면 제공
  • OpenStreetMap, cdnjs(Cloudflare): 지도 그림과 지도 프로그램 제공
  • Discord: 운영자에게 새 가게·신고·신청 알림 (연락처와 한마디는 보내지 않아요)

이 서비스들의 서버는 해외에 있을 수 있고, 각 서비스의 접속 기록에는 IP 주소가 남을 수 있어요. 개인정보를 팔거나 그 밖의 곳에 주지 않아요.

5. 내 정보를 보거나 지우고 싶을 때

신청한 연락처나 등록한 내용을 확인하거나 고치고 지워 달라고 할 수 있어요. 사장님 신청의 연락처 수집에는 동의하지 않아도 되고, 그러면 신청만 할 수 없어요.
